Modelo en Cascada

El modelo en Cascada es una metodología de desarrollo de software que organiza el proyecto mediante una serie de etapas secuenciales. Cada etapa debe completarse antes de continuar con la siguiente.

Clasificación principal

Tradicional

Cascada pertenece a las metodologías tradicionales porque sigue un proceso definido desde el comienzo y las actividades se desarrollan siguiendo un orden establecido.

Características principales

Proceso secuencial

Las etapas se realizan una después de otra siguiendo un orden.

Planificación inicial

Los requisitos y actividades se definen principalmente al comienzo.

Documentación

Cada fase produce información y documentos que sirven para la siguiente.

Pocos cambios

Funciona mejor cuando los requisitos permanecen estables.
